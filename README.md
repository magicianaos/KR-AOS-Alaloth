# Alaloth: Champions of The Four Kingdoms 한국어 패치

비공식 팬 번역 한글패치입니다. **Steam 정품**으로 설치된 게임에서만 설치됩니다.

## 내려받기

[**Releases**](../../releases/latest)에서 `Alaloth_KR_Patch_v1.0.exe`를 받으세요.

## 설치

1. 게임을 완전히 종료합니다.
2. `Alaloth_KR_Patch_v1.0.exe`(한글패치 런처)를 실행합니다. Steam 게임 폴더를 자동으로 찾습니다.
3. **[패치 설치하기]**를 누릅니다. (1~3분, 여유 공간 약 2GB)
4. 게임 설정의 언어 목록에서 **한국어**를 고릅니다.

되돌리기: 런처의 한글패치 메뉴 → **[원래대로 되돌리기]** 또는 Steam의 "게임 파일 무결성 검사".

## 안내

- 대상: Steam판, 빌드 23877818
- 번역 범위: 퀘스트·대화·아이템·캐릭터 정보·UI·영상 자막 등 21,061개 문장
- 이 저장소와 배포 파일에는 **게임 파일이 들어 있지 않습니다.** 런처가 내 PC의 게임에 번역을 넣습니다.
- 게임이 업데이트되면 한글이 사라질 수 있습니다. 런처에서 [패치 설치하기]를 다시 누르세요.
- 서명되지 않은 프로그램이라 Windows SmartScreen 경고가 뜰 수 있습니다. [추가 정보] → [실행]을 누르세요.
